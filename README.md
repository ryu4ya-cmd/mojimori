# もじもじの もり

幼児向けの、ひらがな・カタカナの もじあそびです。ブラウザで開くだけで遊べます。

**あそぶ：https://ryu4ya-cmd.github.io/mojimori/**

iPhone・iPad の Safari で開いて「共有 → ホーム画面に追加」をすると、アプリのように全画面で遊べます。

## あそびかた

ホームで「ひらがな」か「カタカナ」を選んでから、あそびかたを選びます。

- **ふれてみよう**：五十音表（あ）と濁音・半濁音の表（が）を切りかえて遊べます。字をさわると、その字のことばと絵が出てきて、声で読みあげます。さわるたびに、ことば・動き・演出が変わります。
- **さがしてみよう**：「『り』は どーこだ？」と聞かれた字を、おともだちの中から見つけます。
- **これ なあに？**：絵（🍎 など）を見て、そのことばの最初の字を選びます。

まちがえても失敗にはなりません。正解のおともだちが手をふって教えてくれます。

## 保護者の方へ

- 右下の ⚙️ を長押しすると、保護者メニューが開きます。読み上げの声の種類・高さ・速さ、BGMの音量、ずかんのリセットができます。
- 声はブラウザの読み上げ機能を使います。Microsoft Edge の「Nanami（ナチュラル）」や、iPhone・iPad で追加できる「O-ren（拡張）」「Kyoko（拡張）」を選ぶと、なめらかになります。
- ホーム右上の 🎵 で BGM を消せます。
- ずかん（集めた字の記録）は、その端末のブラウザの中だけに保存されます。

## ファイル

- `src/game.html`：ゲーム本体。直すときはこのファイルを編集します。
- `tools/build.py`：`src/game.html` から `index.html` を作ります（`python3 tools/build.py`）。
- `index.html`：公開用のページ（自動で作られるので、直接は編集しません）。
- `icons/`、`manifest.webmanifest`：ホーム画面に追加したときのアイコンと設定。
