# もじもじの もり

幼児向けの、ひらがな・カタカナの もじあそびです。ブラウザで開くだけで遊べます。

**あそぶ：https://ryu4ya-cmd.github.io/mojimori/**

iPhone・iPad の Safari で開いて「共有 → ホーム画面に追加」をすると、アプリのように全画面で遊べます。

## あそびかた

ホームで「ひらがな」か「カタカナ」を選んでから、あそびかたを選びます。

- **ふれてみよう**：五十音表（あ）と濁音・半濁音の表（が）を切りかえて遊べます。字をさわると、その字のことばと絵が出てきて、声で読みあげます。さわるたびに、ことば・動き・演出が変わります。
- **さがしてみよう**：「『り』は どーこだ？」と聞かれた字を、おともだちの中から見つけます。
- **これ なあに？**：絵（🍎 など）を見て、そのことばの最初の字を選びます。
- **しゃぼんだま**：下からのぼってくる、字の入った しゃぼんだまを さわって わります。わると、その字を声で読みます。ときどき「『あ』は どーこだ？」と聞かれるので、その字の しゃぼんだまを さがして わります（見つからないときは、しゃぼんだまが光って教えてくれます）。5つ見つけると おしまいです。
- **はたらくくるま**：しょうぼうしゃ・パトカー・きゅうきゅうしゃ・バス・トラクター・トラック・クレーン・タクシーの8台。上の 🚗 では、くるまをさわると、なまえを言って道を走り、かじを消したり、ひとや にもつを のせたりします。サイレンやクラクションの音も鳴ります。❓ では「たいへん！ かじだ！」のような困りごとを見て、たすけに行く くるまを選びます。
- **いすとり**：じぶんのどうぶつを選んで、ほかの どうぶつたちと いすとりゲームをします。音楽は「オクラホマミキサー」（アメリカ民謡、著作権切れ）で、音は ゲームの中で作っています。音楽が止まったら、あいている いすを さわって すわります。音楽が鳴っているあいだに さわると、ずっこけます（音が一瞬だけ消える ひっかけもあります）。座れなかった どうぶつは、旗をふって おうえんにまわります。子どもが 座りそびれたときは、ほかの どうぶつが「どうぞ」と ゆずってくれるので、子どもが ぬけることはありません。3回目と4回目は「『り』の いすに すわろう！」と字の いすを さがします。5回目の さいごの いすを取ったら ゆうしょうです。あいてが すわりにくる速さは、子どもの速さに合わせて変わります。

正解すると、大きな はなまる とファンファーレでお祝いします。つづけて当てると「3れんぞく！」、5問ぜんぶ終わるとトロフィーが出ます。
まちがえても失敗にはなりません。正解のおともだちが手をふって教えてくれます。

## 声について

ゲームの声は、Style-Bert-VITS2 モデル「小春音アミ」で前もって作った声（`voice/`）を使っています。
このモデルは、[あみたろの声素材工房](https://amitaro.net/) の声をもとにしたものです（モデルの作者：litagin さん。[利用規約](https://huggingface.co/litagin/sbv2_koharune_ami)）。
声のファイルがない場所（claude.ai の公開ページなど）では、端末の読み上げ機能を使います。

## 保護者の方へ

- 右下の ⚙️ を長押しすると、保護者メニューが開きます。ゲームの声と端末の読み上げの切りかえ、読み上げの声の種類・高さ・速さ、BGMの音量、いすとりの あいての速さと字の いすを出すかどうか、ずかんのリセットができます。
- ホーム右上の 🎵 で BGM を消せます。
- ずかん（集めた字の記録）は、その端末のブラウザの中だけに保存されます。

## 古いタブレットで遊ぶとき

古いブラウザでも動くようにしています。dtab d-01H（Android 5.1.1）に入っている Chrome 67 と同じ版の Chromium で、すべてのモードが動くことを確かめています（目安は Chrome 49 以降）。

- 端末に新しい絵文字がなくて□になるときは、ゲームについている絵文字フォント（`fonts/emoji.ttf`）に自動で切りかわります。
- うまく動かないときは画面の上に案内が出ます。保護者メニューの下のほうに、使っているブラウザのバージョンが出ます。

## ファイル

- `src/game.html`：ゲーム本体。直すときはこのファイルを編集します（claude.ai の公開ページもこのファイル）。
- `tools/build.js`：`src/game.html` から `index.html` を作ります。古いブラウザでも動くように、スクリプトの書き方を Babel で変換します。
  はじめの1回だけ `npm install`、そのあとは直すたびに `npm run build`。
- `index.html`：公開用のページ（自動で作られるので、直接は編集しません）。
- `icons/`、`manifest.webmanifest`：ホーム画面に追加したときのアイコンと設定。
- `voice/`：ゲームの声（mp3 と、セリフの部品 → ファイル名の表 `index.json`）。セリフを足したら `tools/make_voice.py` で足りない分を作ります（作り方はスクリプトの先頭に書いてあります）。
- `tools/voice_lines.js`：ゲームで使う声の部品をぜんぶ出します（`tools/make_voice.py` が使います）。
- `fonts/`：古い端末向けの絵文字フォント（Noto Color Emoji から使う絵文字だけを抜き出したもの。ライセンスは `fonts/OFL.txt`）。
  ゲームに絵文字を足したら `python3 tools/make_emoji_font.py` で作り直します（fonttools が必要）。
